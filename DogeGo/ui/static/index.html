            school What am I syncing?
            
Headers prove the chain (PoW, height, time). Connected is chainActive ... the last block validated through ConnectBlock (what RPC getblockcount / blocks report). Stored bodies are contiguous full blocks on disk under rawblocks/ and can run ahead of connected height during IBD.

            
DogeGo stores headers.bin, block bodies under rawblocks/, and indexes under indexes/ in your data directory ... no Dogecoin Core blocks/ or chainstate/ layout.

              Backup your wallet
              
    Download a copy of wallet.json and store it offline in a safe place. Without a backup you cannot recover funds if this device fails.
    
              
    Plaintext wallet.json contains your HD seed and private keys. Dashboard PIN locks the web UI only. Run Console → encryptwallet to encrypt the wallet file on disk.
    
              
    Two backup paths: Download backup (wallet.json) restores this DogeGo wallet including PQ settings. For Dogecoin Core or other wallets, use Console → dumpwallet (standard DOGE keys only; PQ carrier keys are not portable).
    
              
    If you have not rotated keys in a while, consider moving funds to a fresh HD wallet.
    
            
    
            
    
              
              
              
            
    
          
    
          
    
            
    Auto key rotation generates a new HD wallet, sweeps your full balance to it, verifies the old wallet is empty, then switches DogeGo to the new keys. Download a backup first.

                expand_more DogeGo relay (CGNAT)
                
      
              
      
                
      Two roles: pick one. This is separate from Dogecoin P2P port 22556 (TCP).
      
                
      
                  
      
                    Use a relay (CGNAT client)
                    
      For Starlink, mobile, or home networks without inbound. You dial out to a public DogeGo relay over QUIC UDP, with no router port forward on your side.
      
                    
      Your node: outbound UDP to relay:24433 · Dogecoin P2P stays outbound TCP only.
      
                  
      
                  
      
                    Run a relay (public operator)
                    
      For a VPS or home server with a public IP. You host the QUIC relay so CGNAT clients can tunnel through you.
      
                    
      Forward UDP 24433 on your router/firewall to this machine (TCP 22556 is normal P2P, not the relay).
