Full node downloads the chain. Recommended disk layout is on by default: bundled blk*.dat files, zstd compression, and a compact tx index (full explorer search still works).

Full node downloads header chain first, then block bodies toward genesis (IBD). The tx index maps txids to blocks for explorer lookups. Compact index stores only block pointers (not duplicate tx bytes). Analytics sidecar is optional Pebble ... safe to disable on small disks.

SPV mode ... full-node sync options are not used. Continue to P2P.
