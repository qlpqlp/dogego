terminal

Run from the terminal

DogeGo is a single Go binary. Download from GitHub Releases or build from source, then start the node. The dashboard and JSON-RPC come up automatically.

1
Download or build

cd DogeGo && go build -o dogego ./cmd/dogego

2
Start the node

./dogego or ./dogego node -network mainnet

3
Open the dashboard

Browser at 127.0.0.1:2013. First run opens the setup wizard.

Built beyond Dogecoin Core

DogeGo ships operator tooling, indexing, and modern network modes that Core never bundled, in one Go binary with a browser dashboard.

shield

Post-Quantum commitments

First Dogecoin full node with Phase-1 PQ OP_RETURN carriers (FLC1, DIL2, RCG4). Send with automatic wallet commitments, verify via dogego_verifypqcommitment, and inspect in the explorer.

compress

zstd block compression

Optional zstd on stored block bodies plus a bundled blk*.dat layout. Core keeps raw blocks uncompressed. DogeGo reports compression ratio and disk savings in the dashboard.

dns

Full node or SPV

Run headers-first IBD with full validation, or switch to lightweight SPV (headers only) for minimal disk. Same binary, same wizard. Pick your profile on first run.

satellite_alt

CGNAT & Starlink relay

P2P modes: classic, cgnat (outbound-only), or both. Up to 12 outbound peers relay blocks without inbound port forwarding, built for carrier NAT and Starlink.

science

Reboot testnet

Fresh testnet with addresses starting with T (for test). Real scrypt PoW like Core (RelaxedPoW off). Digishield min-difficulty helps solo mining when hashrate is low. Port 44556.

search

Search everything

Full tx index by default. Search height, block hash, txid, or address from the dashboard. Dogecoin is a public ledger, and DogeGo makes every entry easy to find.

dashboard

Web dashboard

Loopback UI at :2013: KPI cards, auto-update banner, sync dock, mempool, analytics, embedded Docs, Features cert matrix, and the five-step setup wizard. No Qt install required.

integration_instructions

180+ JSON-RPC methods

Core-compatible HTTP JSON-RPC with cookie auth, ZMQ notifications, OpenRPC at /api/openrpc.json, and live capability flags in the Features tab.

account_balance_wallet

Built-in HD wallet

Send, receive, and history with BIP44 HD wallet, PIN unlock, optional WebAuthn biometrics, coin control, fee hints, and PQ commitment overrides on send.

system_update

Built-in auto-update

The node checks GitHub Releases daily for semver tags newer than your build. Overview and Settings show a banner with release notes and a direct binary download when a matching platform asset exists.

backup

Wallet backup reminders

First-run setup requires downloading wallet.json before start. On Receive, a recurring banner reminds you to back up offline - dismiss for 30 days, or rotate HD keys with an guided sweep to a fresh wallet.

hub

DogeGo relay CGNAT (DGR)

QUIC tunnel for peers behind carrier NAT. Wizard and Settings configure dogego_relay_cgnat roles (Off / Client / Operator), TLS cert pinning, relay DNS seeds, and live metrics on GET /api/dgr.

layers

Dual mainnet + testnet

Run both networks from one data folder with the Mainnet + testnet wizard profile. Separate mainnet/ and testnet/ chain dirs, dual dashboards (:2013 / :2014), solo mining on testnet only.

precision_manufacturing

Miner ready (Core parity)

getblocktemplate with Digishield NextBlockBits + BIP22 longpoll, createauxblock/submitauxblock for merge-mining, and reboot-testnet solo mining with mempool txs. Certified live via GET /api/core-mining-probe and dogego cert mining.

bolt

BIP152 compact blocks

sendcmpct HB negotiation with up to three peers, cmpctblock announce/reconstruct, and getblocktxn fallback. Live probe at GET /api/core-bip152-probe.

pending_actions

Mempool relay policy

Wizard and Settings expose Core-shaped flags: maxmempool, minrelaytxfee, incrementalrelayfee, package limits, Full RBF, datacarrier, and bare multisig - plus a 58-template offline admission corpus.

download_for_offline

Parallel block download

Faster, more stable multi-peer IBD: block-assist workers, height striping, auto UTXO dbcache, and Core-style IBD focus so download stays productive through long syncs.

extension

Modular extension platform

Install and enable catalog packages without changing Dogecoin consensus: zip or GitHub install, subprocess/wasm hosts, allowlisted permissions, optional wallet_rpc, and host-rendered UI panels. See the Extensions section for each official package.

verified

SegWit ready

BIP141 interpreter, witness serialization, and weight/vsize helpers ship today, Core-aligned with Dogecoin Core. CLTV is already active. Softfork follows Core’s schedule; see SEGWIT_STATUS.md for upgrade effects on nodes and miners.

notifications

System tray & notifications

Optional tray icon: open dashboard, check/download/install updates with SHA256 verify, and native OS notifications when a new GitHub release is detected.

Official extensions

Optional catalog packages you install beside the node. They do not fork mainnet consensus. Install from Settings → Extensions or the GitHub catalog, then enable.

psychology

dogego.zkl2

ZK Layer 2

Submit and sync ZK proofs anchored to confirmed Dogecoin txs over the zkproof-v1 P2P overlay. No L1 consensus fork. Mainnet + testnet.

collections

dogego.doginals

Doginals / DRC-20 L2

Index L1 Doginals/DRC-20 carriers, mint via allowlisted wallet RPC, and sync off-chain NFT/token metadata among peers (doginals-v1). Mainnet + testnet.

cell_tower

dogego.radiodoge

RadioDoge

Connect a Heltec V3 SoftAP device: broadcast signed txs over LoRa when offline, and relay inbound mesh txs into DogeGo with sendrawtransaction when online. Same HTTP API as Dogecoin Wallet RadioDoge support.

currency_bitcoin

dogego.bbpow

BBPoW research

Testnet-only research toward Bitcoin SHA-256 commitments as a Dogecoin security signal (not AuxPoW, not mainnet consensus). Proof verify RPC and dual-lane difficulty sketch.

Author your own packages too. Docs: EXTENSIONS.md · catalog on GitHub.

Full Dogecoin node - what DogeGo runs today

Headers-first IBD with parallel body download, auto dbcache, IBD optimize (default on), Go-native storage, Core-compatible JSON-RPC, and operator tooling in one binary. Mainnet consensus follows Dogecoin Core (no protocol forks).

Live in the app & wizard

sync

Chain sync & IBD

Headers-first sync with parallel body download, auto dbcache, IBD optimize (default on), journal recovery, and a sync dock with recent download rate and assist pool metrics.

gavel

Validation & mempool

Block/header checks, AuxPoW CAuxPow parity, in-memory UTXO cache with snapshot replay, 58-template mempool admission corpus, BIP125 RBF, feefilter, savemempool/loadmempool.

hub

P2P networking

classic / cgnat / both, UPnP/NAT-PMP, learned addr store, addnode, setban, multi-peer relay, DGR QUIC tunnel, BIP152 v1 compact blocks.

api

JSON-RPC & ZMQ

180+ methods, cookie auth, getblocktemplate BIP22, mining/aux RPC, estimatesmartfee, ZMQ hash/raw block+tx notifications, OpenRPC and RPC cookbooks in Settings → Tools.

account_balance_wallet

Wallet & migration

BIP44 HD per network, wizard backup + optional encryptwallet, fill-to-target keypoolrefill, PSBT/HWI, Core wallet.dat import + pool replay, coin control, Tx Flight, and wallet.db scan index for fast history (auto-rescan when the index lags).

settings

Operator UX

Five-step wizard with five profiles, preflight (firewall, ports, CGNAT, founder), OS autostart, GitHub auto-update, 17 live cert web probes (mining GBT/aux), embedded Docs, analytics Pebble sidecar, dogego cert offline gates.

extension

Modular extensions

Catalog / zip install, subprocess and wasm hosts, runtime permission checks, host-rendered UI panels, and dynamic RPC dogego_ext_<id>_<method>. See Official extensions for ZK L2, Doginals, RadioDoge, and BBPoW.

Operator experience built in

DogeGo is more than sync and RPC - the loopback dashboard includes everyday tooling Core never shipped in one place.

system_update_alt

Release notifications

Daily update check against the canonical github.com/qlpqlp/dogego repo. CLI prints hints too; dismiss per release from the web UI or POST /api/update/dismiss.

notifications_active

Backup nudges every 30 days

Receive tab shows a wallet backup banner until you download a copy or snooze for 30 days. Setup wizard blocks Save & start until backup is acknowledged when the wallet is enabled.

sync_lock

HD key rotation

One-click prepare → sweep → verify → finalize flow moves your balance to a fresh BIP44 wallet and archives the old keys - with backup required first.

login

OS login autostart

Register at sign-in on Windows (Task Scheduler), Linux (systemd user), or macOS (LaunchAgent). Wizard and Features tab run the same probes as dogego cert autostart.

flight_takeoff

Tx Flight send bar

Animated progress when you send: signing, broadcast, mempool wait, and confirmation - with one-click jump to History or the block explorer.

translate

Six dashboard languages

English, Deutsch, Français, Português, 日本語, and 中文 - wizard and dashboard share the same locale picker in the top bar.

pin

PIN & WebAuthn lock

Optional 6-digit dashboard PIN on setup or in Settings. Pair with device biometrics (WebAuthn) to unlock Send and wallet views without retyping every time.

menu_book

Embedded Docs tab

Operator runbooks, integration guides, and repo markdown rendered in-browser via GET /api/docs - no GitHub tab required while you tune the node.

verified

Live cert matrix

Features tab exposes Core parity counts, OpenRPC at /api/openrpc.json, and seventeen live operator web gates (compare, mempool, mining GBT/aux, autostart, founder, BIP152, IBD convergence, runner readiness, end-to-end, and more).

sync

Fixed sync dock

Core-style footer during IBD: connected vs stored bodies, assist pool, recent download rate, connect lag, ETA, and expandable live logs - always visible while you browse tabs.

shield

Firewall & preflight

Setup wizard runs automatic checks for ports, CGNAT hints, and optional OS firewall rules. Copy-paste elevated commands appear on Overview when action is needed.

receipt_long

History that scales

Infinite-scroll transaction feed with server-side search and type filters, CSV export, UTXO-cache fast path for solo miners, and soft refresh that preserves scroll position.

extension

Extensions catalog

Settings → Extensions installs packages from GitHub or zip. Enable what you need; wallet access only via authenticated allowlisted RPC when an extension opts in. Browse packages in Official extensions.

Beta: try it

DogeGo is a pure-Go Dogecoin full node with Core-compatible consensus, RPC, wallet migration, and mining. It is beta: please run it on testnet or mainnet, try the workflows you care about, and tell us what needs tuning. Storage uses DogeGo’s native layout (not Core LevelDB); optional long-haul self-cert is in the dashboard Features tab (dogego cert live-soak).
